# 开屏跳过助手 · 用户说明书

> 一句话：帮你自动点掉手机 App 开屏广告上的「跳过 / 关闭」按钮。

---

## 一、这是什么 App？

打开手机 App 时，开屏广告常需要手动点一下「跳过」才能进入。本 App 利用安卓系统的**无障碍服务**，在目标 App 冷启动后的几秒内，自动识别并点击右上角的「跳过 / 关闭」按钮，帮你快速进入。

**特点**

- ✅ 纯本地运行，**不联网、不上传任何数据**（无任何网络权限）
- ✅ 只对规则里的目标 App 生效，非目标 App 完全不碰
- ✅ 每次开屏**最多点一次**，多重防误触
- ✅ 内置高德地图规则，其他 App 可通过规则或「学习模式」添加
- ⚠️ 只点开屏「跳过」，**绝不点击**「支付 / 登录 / 权限 / 同意 / 下载」等敏感按钮

**小知识：什么是“包名”？** 每个安卓应用都有唯一标识，比如高德地图是 `com.autonavi.minimap`。添加规则或学习模式时需要填写它；可以在本 App 的「日志」页抓取当前前台 App 自动看到。

## 二、安装

1. 下载 APK（见仓库 Release 页面，或问开发者要安装包文件）；
2. 手机弹出「未知来源应用」提示 → 允许本次安装；
3. 安装完成后打开本 App。

---

## 三、首次设置（必须开启无障碍服务）

1. 打开 App，首页显示「无障碍服务：未开启」；
2. 点击「去开启无障碍服务」，会跳转到系统无障碍设置；
3. 找到「**开屏跳过服务**」→ 打开开关 → 在系统弹窗中确认；
   （部分手机有“安全提醒”，属安卓系统对所有辅助功能的通用提示，确认即可）
4. 返回本 App，首页显示「无障碍服务：已开启」即成功。

**30 秒快速验证**：把高德地图从最近任务里划掉 → 重新打开 → 开屏出现「跳过」时应自动点击进入主页 → 到本 App「日志」页可看到点击记录。

## 四、五个页面怎么用

### 1️⃣ 首页

| 内容 | 说明 |
|---|---|
| 服务状态卡 | 无障碍服务是否开启（绿=已开启，红=未开启） |
| 自动跳过总开关 | 一键暂停 / 恢复自动跳过 |
| 今日跳过 | 今天成功跳过的次数 |
| 启用规则 | 当前生效的规则数量 |
| 最近日志 | 点「查看 →」直接进入日志页 |

### 2️⃣ 日志页（排查问题的好帮手）

- 每次点击都会记录：时间、App 包名、命中规则、按钮文本、得分、动作、**成功或失败原因**；
- 顶部可筛选：按 App、按成功 / 失败；
- 右上角：复制（导出纯文本）、清空；
- 「自动抓取」开关：每次切换窗口自动记录当前页面节点树；「立即抓取」：抓取当前窗口。适合排查「为什么不点」。

### 3️⃣ 规则页

- 列表展示每条规则：名称、目标包名、窗口 / 冷却参数、启用开关；
- 内置高德规则带「**内置**」标记，不可删除（防误删）；
- **新建规则**：推荐点顶部模板一键预填（通用跳过 / 倒计时跳过 / × 关闭），再填写规则名称、目标包名、按钮关键词即可；
- **编辑**：支持表单模式与 JSON 模式（高级用户），可互相切换；
- **导入 / 导出**：把规则存成 JSON 文件备份或分享给朋友；
- **最低命中得分**：调高 = 更保守（更难误触），调低 = 更容易点中。

### 4️⃣ 学习页（给任意 App 快速生成规则）

1. 输入目标 App 包名（可在日志页查），点「开始学习」；
2. **学习期间本 App 不会自动点击**，放心操作；
3. 切换到目标 App，等开屏广告出现，**手动点一下「跳过」**；
4. 返回本 App，能看到捕获到的按钮信息与自动生成的候选规则；
5. 点「保存规则」→ 下次打开该 App 就会自动跳过了。

### 5️⃣ 设置页

| 项目 | 说明 |
|---|---|
| 总开关 | 一键停用所有自动点击 |
| 冷启动窗口 | 3–15 秒（默认 8 秒），开屏后多久内有效 |
| 点击冷却 | 1–10 秒（默认 2 秒），两次点击最小间隔 |
| 隐私说明 / 开源许可 / 关于 | 版本与合规信息 |

> 提示：全局参数只会让防误触**更严格**（窗口取更小值、冷却取更大值），放心调整。

## 五、防误触机制（为什么可以放心用）

1. **只碰目标 App**：仅规则包名白名单内的应用才会触发；
2. **只在开屏阶段**：冷启动后 8 秒窗口内有效；
3. **最多点一次**：同一次开屏绝不连点；
4. **冷却 2 秒**：两次点击至少间隔 2 秒；
5. **右上角优先 + 关键词匹配**：按钮需在右上角区域、文本命中「跳过/关闭」且得分达标；
6. **敏感词黑名单**：含「支付 / 登录 / 权限 / 同意 / 下载」等字样的按钮一律不点；
7. **点击前二次校验**：确认按钮此刻仍在屏幕上、可见、可点，才执行。

## 六、常见问题（FAQ）

**Q1：开了服务，为什么不自动跳？**
依次检查：① 服务是否开启；② 首页总开关是否打开；③ 规则页该 App 的规则是否启用；④ 是否“冷启动”（从最近任务划掉后重开）；⑤ 该开屏广告是否有「跳过」文字按钮（个别广告只有倒计时、无按钮）。
→ 看「日志」页会有明确原因（如“窗口内未匹配到目标节点”）；也可以用学习模式重新学一次。

**Q2：会不会误点到别的按钮？**
五重防误触 + 敏感词黑名单已最大限度避免。若仍担心：规则页把「最低命中得分」调高（如 80）、设置页把窗口调小（如 3 秒）。

**Q3：费电吗？**
几乎不费。它只在目标 App 冷启动后的 8 秒内短暂工作，其余时间处于待命状态。

**Q4：我的隐私安全吗？**
安全。本 App **没有任何网络权限**，截图、节点树、日志全部只保存在你的手机里；卸载即彻底清除。

**Q5：怎么彻底停用？**
① 设置页关总开关（暂停）；② 系统无障碍设置里关闭「开屏跳过服务」（完全停用）；③ 直接卸载（移除全部数据）。

**Q6：哪些手机能用？**
安卓 8.0 及以上均可。小米 / 华为 / OPPO / vivo 等系统开启无障碍时的安全提示属系统通用行为。

**Q7：目标 App 提示“检测到无障碍服务”？**
个别 App 会检测辅助功能并弹提示，属正常现象；忽略即可，或按需临时关闭本服务。
