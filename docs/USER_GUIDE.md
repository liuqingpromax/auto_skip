# 开屏跳过助手 · 用户说明书

> 一句话：帮你自动点掉手机 App 开屏广告上的「跳过 / 关闭 / ✕」按钮。
>
> 当前版本以 `app/build.gradle.kts` 的 `versionName` 为准（见 README 开头的版本号与 CI 徽章）；
> 本文档描述的功能自 v0.2.0 起生效，v0.3.0 起支持任意角落的按钮与叉号 ✕ 按钮。

---

## 一、这是什么 App？

打开手机 App 时，开屏广告常需要手动点一下「跳过」才能进入。本 App 利用安卓系统的**无障碍服务**，在目标 App 冷启动后的几秒内，自动识别并点击「跳过 / 关闭 / ✕」按钮，帮你快速进入。

**特点**

- ✅ 纯本地运行，**不联网、不上传任何数据**（无网络权限）
- ✅ 只对规则里的目标 App 生效，非目标 App 完全不碰
- ✅ 每次开屏**最多点一次**，多重防误触
- ✅ 内置高德地图规则，其他 App 用「学习模式」点一下就学会
- ⚠️ 只点开屏「跳过 / 关闭 / ✕」，**绝不点击**「支付 / 登录 / 权限 / 同意 / 下载」等敏感按钮

**三个页面就够了**：首页看状态 →（可选）规则页管规则 → 学习页学新 App。

## 二、安装

1. 下载 APK（仓库 Release 页面，或问开发者要安装包）；
2. 手机弹出「未知来源应用」提示 → 允许本次安装；
3. 安装完成后打开本 App。

## 三、首次设置：开启无障碍服务（必须做，约 30 秒）

> 没开这一步，App 什么都做不了。所以首页会一直提示你。

### 步骤

1. 打开 App，首页显示「无障碍服务：未开启」；
2. 点「**去开启无障碍服务**」按钮，跳转到系统无障碍设置；
3. 在列表里找到「**开屏跳过服务**」→ 打开开关 → 系统弹窗中点「允许 / 确定」
   （弹窗里的“安全提醒”是安卓对**所有**辅助功能的通用提示，不是本 App 的问题）；
4. 返回本 App，看到「无障碍服务：**运行中**」就成功了。

### 找不到「开屏跳过服务」？按你的手机品牌找

| 品牌 | 路径 |
|---|---|
| 小米 / 红米 | 设置 → 更多设置 → 无障碍 → **已下载的应用** → 开屏跳过服务 |
| 华为 / 荣耀 | 设置 → 辅助功能 → 无障碍 → **已安装的服务** → 开屏跳过服务 |
| OPPO / 一加 / realme | 设置 → 系统设置 → 无障碍 → **已安装的服务** → 开屏跳过服务 |
| vivo / iQOO | 设置 → 快捷与辅助 → 无障碍 → **已安装的服务** → 开屏跳过服务 |
| 三星 | 设置 → 辅助功能 → **已安装的应用** → 开屏跳过服务 |
| 其他 | 设置 → 无障碍 → 「已安装的应用 / 已下载的服务」→ 开屏跳过服务 |

> 提示：很多手机在无障碍页顶部有个搜索框，直接搜「开屏」最快。

### 首页显示「已开启（服务待连接）」

这是**手机系统的问题，不是本 App 坏了**——系统记住了授权，却没把服务拉起来。按顺序试：

1. 首页点「刷新状态」，或切到别的 App 再回来（都能触发系统重新连接服务）；
2. 回系统无障碍设置，把「开屏跳过服务」**关掉再打开**一次（最常见有效）；
3. 把本 App 加入**电池优化白名单**（设置 → 电池 → 应用启动管理 → 允许后台运行 / 手动管理全开）；
4. 重启手机，再回首页看状态。

首页的「**机型排查**」按钮里有本机诊断信息（当前机型、系统实际启用的无障碍服务列表、本应用的服务组件名），截图发给开发者可以快速定位问题。

### 30 秒快速验证

把高德地图从最近任务里划掉 → 重新打开 → 开屏出现「跳过」时应自动点击进入主页 → 到本 App「日志」页可看到点击记录。

## 四、学习模式：让任意 App 也能自动跳过 ⭐

> **v0.2.0 重做**：不用再手敲包名，也不用猜流程，跟着数字走就行。

### 一句话理解

**你手点一次「跳过」或 ✕，它学会；以后它替你点。**

### 三步操作（页面顶部也有同样三步图）

| 步骤 | 你要做什么 | 页面会怎么配合 |
|---|---|---|
| **① 选 App** | 在学习页的应用列表里，点一下要学习的 App（如「高德地图」） | 可以搜索应用名；列表默认只显示你自己装的 App，可开关「含系统应用」 |
| **② 点一次「跳过」或 ✕** | App 会**自动帮你打开**目标 App；等开屏广告出现，用手指**点一下**「跳过」文字或那个 ✕ 按钮 | 页面显示橙色「正在学习」卡片 + 进度条 + **60 秒倒计时**，并反复提醒你现在该做什么 |
| **③ 保存规则** | 切回本 App，挑一条候选规则，点「保存这条」 | 页面显示：你点的是什么按钮、在屏幕哪个位置、几条候选规则及推荐度 |

保存后把目标 App 从最近任务划掉再打开一次，就能验证是否自动跳过；结果都记在「日志」页。

### 页面上的东西分别是什么意思

**捕获到的按钮信息**（告诉你“学到了什么”）

| 字段 | 含义 |
|---|---|
| 按钮文字 | 按钮上显示的字，如「跳过 3」，这是最可靠的线索 |
| 无障碍描述 | 按钮给读屏软件的说明，纯图标按钮（如「×」）常只有这个 |
| 控件 ID | 程序内部的控件编号，同一版本最精确 |
| 点击位置 | 你手指点的位置（屏幕百分比）和所在角落 |
| 样本质量 | **好 / 中 / 一般** —— 好就基本能用，一般说明按钮几乎没有可用信息 |

**候选规则**（挑一条保存，推荐度从高到低）

| 候选规则 | 什么时候选它 |
|---|---|
| 按按钮文字匹配（推荐） | 一般情况都选它。界面改版也不容易失效 |
| 按内容描述匹配 | 按钮是纯图标、没有文字时（如只有「×」） |
| 按控件 ID 匹配 | 前两条都不行时。同版本最精确，但 App 更新后可能失效 |
| 按纯图标按钮识别 | 按钮**既没文字也没描述**时的兜底：只要出现「可点击、尺寸小、位于屏幕边缘」的图标就点它 |
| 按位置兜底（保守） | 只在完全没有文字线索时出现。在**你原来点的那个位置**点一次，最不容易误触，但界面变了可能漏点 |

每条候选都带「**推荐度**」和「**命中阈值**」：推荐度越高越省心；阈值越高越保守（更不容易误点）。

**关于按钮位置：跳过/关闭按钮不一定在右上角。** 左上角、右下角、左下角、顶部通栏、底部横幅都很常见，本应用对这些位置一视同仁；位置只是「加分项」——四角加分最高，屏幕正中间不加分（防止误点内容区）。所以你点哪个角落它就学哪个角落。

**关于叉号按钮：** 很多广告的关闭按钮就是一个 **✕** 图标，没有「跳过」两个字。本应用会识别这类「可点击 + 尺寸小 + 位于边缘」的纯图标按钮，你照常点它一下就能学会。

**关于倒计时按钮：** 带倒计时的按钮有**两种写法**，本应用都能学、也都能认，而且**不限倒计时数字**：

| 写法 | 例子 |
|---|---|
| 数字在后 | `跳过3`、`跳过 5`、`跳过3s`、`跳过 5 秒` |
| 数字在前 | `3跳过`、`3 跳过`、`5秒后跳过`、`3s跳过`、`3s后跳过` |
| 英文 | `skip 3`、`3 skip`、`Skip in 3s` |
| 全角数字 | `跳过３`（部分手机的广告用全角渲染） |

也就是说：你学到的是「倒计时显示 3 秒」那一刻的按钮，之后倒计时变成 5、2、1 秒，规则照样命中 —— 不会因为数字变了就失效。

**「先试跑一下」按钮**：在保存前用最近一次窗口快照判断这条规则能不能命中，命中会告诉你得分和按钮文字。如果提示「没有找到匹配节点」，通常只是因为开屏已经结束，保存后照常验证即可。

### 学习失败了怎么办？

| 现象 | 原因与处理 |
|---|---|
| 提示「没拿到可用线索」 | 按钮既没文字、也没描述和 ID，且不是边缘区的小图标。换点广告上的「×」或「跳过」，或换 App 再学一次 |
| 学习超时（60 秒没捕获到） | 目标 App 没真的打开，或开屏广告还没出现你就切走了。重新学一次，注意要**用手指点**「跳过 / ✕」 |
| 点错了按钮（比如点进了广告） | 点「**重新学习一次**」，再点一次正确的「跳过 / ✕」即可 |
| 学到的是倒计时数字 | 不用担心：不管数字写在前面还是后面，规则都会把数字剥掉，之后倒计时变成几秒都能命中 |
| 点了关闭按钮却提示被忽略 | 只有「屏幕中间的大块内容区」会被忽略（防止学到广告本身）。四角、上下边缘、左右边缘的按钮都会正常记录 |

> 补充说明：一次学习**只记一个按钮**（点一下即完成），所以点错了就重学，不会污染结果；学习时长 60 秒，超时自动结束，不会一直在后台跑。

## 五、五个页面怎么用

### 1️⃣ 首页

| 内容 | 说明 |
|---|---|
| 服务状态卡 | 三态显示：未开启（红）/ 已开启待连接（橙）/ 运行中（绿）；带「刷新状态」和「机型排查」 |
| **让新 App 也能自动跳过** | 学习模式入口卡，点「进入学习模式 →」直接跳到学习页（不用自己去底部导航找） |
| 自动跳过总开关 | 一键暂停 / 恢复自动跳过 |
| 今日跳过 | 今天成功跳过的次数 |
| 启用规则 | 当前生效的规则数量 |
| 最近日志 | 点「查看 →」直接进入日志页 |

### 2️⃣ 日志页（排查问题的好帮手）

- 每次点击都会记录：时间、App 包名、命中规则、按钮文本、得分、动作、**成功或失败原因**；
- 学习模式的捕获也会记一条：事件类型 `LEARNING`，明细里写明「捕获方式」；
- 顶部可筛选：按 App、按成功 / 失败；
- 右上角：复制（导出纯文本）、清空；
- 「自动抓取」开关：每次切换窗口自动记录当前页面节点树；「立即抓取」：抓取当前窗口。适合排查「为什么不点」。

### 3️⃣ 规则页

- 列表展示每条规则：名称、目标包名、窗口 / 冷却参数、启用开关；
- 内置高德规则带「**内置**」标记，不可删除（防误删）；
- **新建规则**：推荐点顶部模板一键预填（通用跳过 / 倒计时跳过 / × 关闭），再填写规则名称、目标包名、按钮关键词即可；
- **编辑**：支持表单模式与 JSON 模式（高级用户），可互相切换；
- **导入 / 导出**：把规则存成 JSON 文件备份或分享给朋友；
- **最低命中得分**：调高 = 更保守（更难误触），调低 = 更容易点中。

### 4️⃣ 学习页

见上面第四章。

### 5️⃣ 设置页

| 项目 | 说明 |
|---|---|
| 总开关 | 一键停用所有自动点击 |

## 六、防误触机制（为什么可以放心用）

1. **只碰目标 App**：仅规则包名白名单内的应用才会触发；
2. **只在开屏阶段**：冷启动后 8 秒窗口内有效；
3. **最多点一次**：同一次开屏绝不连点；
4. **冷却 2 秒**：两次点击至少间隔 2 秒；
5. **关键词匹配 + 位置加权**：文本需命中「跳过 / 关闭 / ✕ / skip / close」等关键词（**倒计时数字写在前面或后面都会先剥掉**，所以「跳过3」「3跳过」等价）；位置作为加分项——四角 +25、上下边缘 +18~22、左右边缘 +10、**屏幕正中间 0 分**。因此中间的纯图标不会被点，而各个角落的按钮都能点到；
6. **纯图标按钮有严格门槛**：必须是「可点击 + 无文字 + 无描述 + 尺寸小（宽 ≤22% 屏宽）+ 位于屏幕边缘」才认，大块内容区一律不算；
7. **敏感词黑名单**：含「支付 / 登录 / 权限 / 同意 / 下载 / 立即 / 领取」等字样的按钮一律不点；
8. **点击前二次校验**：确认按钮此刻仍在屏幕上、可见、可点，才执行；
9. **学习期间绝不自动点击**：学习时服务只观察、不动作。

## 七、常见问题（FAQ）

**Q1：开了服务，为什么不自动跳？**
依次检查：① 首页状态是否为「运行中」（橙色状态见第三章处理办法）；② 首页总开关是否打开；③ 规则页该 App 的规则是否启用；④ 是否“冷启动”（从最近任务划掉后重开）；⑤ 该开屏广告是否有「跳过 / 关闭 / ✕」按钮（个别广告只有倒计时、无按钮）。
→ 看「日志」页会有明确原因（如“窗口内未匹配到目标节点”）；也可以用学习模式重新学一次。

**Q2：会不会误点到别的按钮？**
八重防误触 + 敏感词黑名单已最大限度避免。若仍担心：规则页把「最低命中得分」调高（如 80）、设置页把窗口调小（如 3 秒），或在学习页选推荐度低但更保守的「按位置兜底」。

**Q3：费电吗？**
几乎不费。它只在目标 App 冷启动后的 8 秒内短暂工作，其余时间处于待命状态；学习模式也只持续 60 秒。

**Q4：我的隐私安全吗？**
安全。本 App **没有任何网络权限**，截图、节点树、日志全部只保存在你的手机里；学习模式只读取本机应用列表用于让你选 App，不上传。卸载即彻底清除。

**Q5：怎么彻底停用？**
① 设置页关总开关（暂停）；② 系统无障碍设置里关闭「开屏跳过服务」（完全停用）；③ 直接卸载（移除全部数据）。

**Q6：哪些手机能用？**
安卓 8.0 及以上。v0.2.0 针对小米 / 华为 / 荣耀 / OPPO / vivo / 三星等机型的无障碍状态判断做了适配（多格式检测 + 三态显示 + 分品牌路径提示）；系统开启无障碍时的安全提示属通用行为。

**Q7：目标 App 提示“检测到无障碍服务”？**
个别 App 会检测辅助功能并弹提示，属正常现象；忽略即可，或按需临时关闭本服务。

**Q8：升级到 v0.2.0 后服务失效了？**
系统在应用更新后会重置无障碍授权，重新开启一次开关即可；首页「刷新状态」可立即重新检测。
